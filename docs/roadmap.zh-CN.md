# 路线图：Onshape 工业结构 Agent

## 目标

把真实结构工程经验沉淀成 AI 可以复用的 Onshape/CAD 技能。短期服务智能断路器结构项目，长期扩展到更高价值的工业硬件方向，例如液冷机柜。

## 1. 需要系统学习的资料

### CAD 自动化基础

- Onshape REST API：文档、工作区、元素、Part Studio、Assembly、导入导出、翻译任务。
- FeatureScript：参数化特征、变量、草图、拉伸、扫掠、实体选择、错误处理。
- Onshape MCP 项目：重点研究 `jarvis-onshape-mcp` 和 `hedless/onshape-mcp` 的工具设计、返回结构、视觉检查流程。
- CadQuery/OCP：用于本地生成 STEP、修复简单几何、做参数化标准件。
- STEP/Parasolid/STL/DXF/DWG 基础：知道哪些格式保留实体，哪些只是网格或图纸。

### Agent 建模方法

- 把工程动作拆成小工具，而不是一次性让 AI “完成模型”。
- 每个工具必须有输入参数、输出文件、检查项和失败原因。
- 建模后必须做视觉或几何验证：bbox、体积、实体数量、干涉、关键尺寸。
- 对真实产品，优先让工程师给约束，再让 AI 执行。

### 制造业结构知识

- 塑胶壳体：脱敏简化、筋位、卡扣、柱位、拔模、壁厚、外观保留。
- 小五金：铆钉、螺钉、弹簧、端子、铜排、轴、销。
- 工程图：关键尺寸、装配尺寸、公差、供应商沟通图。

## 2. 短期规划：用非开源项目练手

建议使用公司真实项目练手，但仓库和输出分两层：

- 私有层：真实项目、真实 STEP/PRT/ASM、真实截图，只在本机或私有仓库。
- 公开层：抽象后的 skill、脚本、假数据、小样件、通用说明。

### 第一个练手项目

继续围绕智能断路器，优先做 3 个小闭环：

1. 扭簧生成与替换  
   输入丝径、外径、圈数、脚长、脚方向，输出 STEP，并能上传/替换 Onshape 装配实例。

2. 外壳供应商脱敏  
   保留外部轮廓、安装孔和必要装配界面，抹平内部结构，输出供应商可用 STEP。

3. 铆钉/螺钉推断  
   根据孔径、沉孔、壳厚、装配关系，生成候选规格和简化装配模型。

### 2026-05-28 新增闭环：STEP 视图检查

今天确认 `step-inspector` 是电表布局项目的关键前置能力。它解决的问题是：agent 必须先拿到工程师真正认可的 CAD 视图，再谈布局和建模。

短期目标：

- 从 STEP 生成与 Onshape 视图立方体一致的左视图；
- 支持隐藏壳体后观察内部结构；
- 支持编号实体，方便用户指出零件；
- 记录正确视图参数，避免左右视图反复错误；
- 后续扩展为端子区、齿轮区、连接器区、铜排路径的候选识别器。

### 短期成果标准

- 每个能力都有 `SKILL.md`。
- 每个能力至少有一个可运行脚本。
- 每个能力至少有一个中性示例，不暴露公司产品。
- 每次真实项目经验都转化成公开可讲的规则。

## 3. 长期方向：液冷机柜

液冷机柜方向可行，而且值得关注，但它不是单纯结构件项目。它涉及结构、热管理、流体、管路、密封、电气安全、维护和供应链。

### 可行切入点

不要一开始做完整产品。先做一个“液冷机柜结构概念验证”：

- 机柜框架和门板结构。
- CDU 或分配单元占位。
- 供回液主管路和歧管。
- 快插接头、软管走线、泄漏检测安装位。
- 服务器/电池/功率模块冷板接口占位。
- 维护空间、抽拉方向、检修门、排水和防滴液路径。

### 需要重点学习

- 数据中心液冷基本架构：冷板式、浸没式、后门换热、机柜级 CDU。
- 冷却液回路：泵、换热器、过滤、补液、排气、排液、传感器。
- 管路与密封：快插、软管弯曲半径、泄漏风险、维护可达性。
- 热设计基础：流量、压降、温升、换热能力、冗余。
- 相关标准与供应商白皮书：优先看公开技术手册和大厂方案，不先闭门造车。

### 风险

- 热/流体计算不能只靠结构经验，需要验证或专业工具。
- 液冷产品对泄漏和维护非常敏感，结构设计要服从可靠性。
- 市场前景好，但供应链和客户验证周期长。

### 建议阶段

1. 资料阶段：收集公开方案，建立术语表和典型架构图。
2. 概念阶段：做 19 英寸机柜/模块化机柜的 Onshape 参数化骨架。
3. 管路阶段：做供回液歧管、快插和软管走线的参数化布置工具。
4. 验证阶段：做基本压降/流量/维护空间检查，不冒充完整热仿真。
5. 样机阶段：选一个具体应用，例如 AI 服务器液冷柜或储能液冷柜。

## 4. 长期方向：COMSOL 仿真能力

液冷机柜不可能只靠 CAD 建模完成，后续一定需要仿真能力支撑。当前已有一个静磁场/低频电磁场 COMSOL 项目经验，可以独立沉淀为仿真 Agent 仓库，再逐步迁移到热/流体方向。

### COMSOL 仿真仓库定位

- 仓库只保存脚本、说明、模板和小型结果数据。
- 不保存 `.mph` 大模型、许可证文件、安装包、破解材料或供应商原始文件。
- 第一阶段聚焦静磁场：模型检查、材料/线圈/Study/Result 导出、相位扫描、传感点曲线。
- 第二阶段连接 CAD：从 Onshape/STEP 得到几何，再为 COMSOL 建立材料和边界条件映射。
- 第三阶段服务液冷机柜：热源、流体入口/出口、流量、压降、温升、维护空间和异常工况。

### 与 Onshape 的关系

Onshape 仓库负责结构和参数化 CAD；COMSOL 仓库负责仿真流程。长期目标是让两者形成闭环：

1. Onshape 生成结构几何。
2. 导出简化 STEP 或参数表。
3. COMSOL 自动建立仿真模型。
4. 输出温度、压降、磁场、传感点曲线等结果。
5. 结果反向指导结构修改。

- 每完成一个真实结构任务，就问：哪些规则可以抽象成 skill，哪些文件必须保密。
