# AI CAD project watch logs

本目录用于固定记录 AI + CAD / CAD MCP / agentic hardware design 方向的新项目和重要更新。

## Rule

- 每次用户要求“检查有没有新项目 / 老项目更新 / AI+CAD 新技术”时，在本目录新增或更新当天日志。
- 文件命名格式：`YYYY-MM-DD.zh-CN.md`。
- 记录范围优先包括：
  - CAD agent / text-to-CAD / prompt-to-CAD；
  - MCP for CAD tools，包括 FreeCAD、build123d、CadQuery、Onshape、KiCad 等；
  - AgentCAD、CAD skill、CAD viewer、STEP inspection and validation；
  - 与硬件结构、机箱、散热、液冷机柜、工程图自动化有关的 agent 工作流。
- 每篇日志至少包含：日期、扫描范围、重要发现、建议动作、来源链接。
